## Como Executar o Projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/nayv380/IFMG.git
   ```

2. Entre na pasta do projeto:
   ```bash
   cd curriculum-vitae
   ```

3. Instale as dependências:
   ```bash
   npm install
   ```

4. Execute o projeto em modo de desenvolvimento:
   ```bash
   npm run dev
   ```

5. Abra o navegador em `http://localhost:5173` para visualizar o currículo.

## Desenvolvimento do Projeto

Este currículo foi desenvolvido utilizando as seguintes ferramentas e tecnologias:

- **Node.js**: Instalei a versão LTS do Node.js (18.x) do site oficial (nodejs.org). Isso foi essencial para executar o npm e o Vite.
- **Vite**: Usei o Vite como bundler e servidor de desenvolvimento. Instalei via `npm create vite@latest` para criar o projeto base.
- **React**: Framework principal para construir a interface. Instalei com `npm install react react-dom`.
- **Tailwind CSS**: Para estilização. Instalei via npm e configurei no Vite.
- **ESLint**: Para linting do código. Já veio configurado no template do Vite.
- **Git**: Para controle de versão. Instalei o Git do site oficial (git-scm.com) e configurei com meu nome e email.
- **VS Code**: Editor de código usado para desenvolvimento, com extensões para React e Tailwind.

### Dificuldades Encontradas e Soluções

- **Configuração Inicial**: No início, enfrentei problemas com a configuração do Tailwind CSS no Vite. Resolvi seguindo a documentação oficial e ajustando o `tailwind.config.js`.
- **Importação de Imagens**: Tive dificuldade com o caminho da imagem do avatar. Corrigi renomeando o arquivo e ajustando o import no código.
- **Estrutura de Dados**: Organizar os dados do currículo em um objeto JavaScript foi desafiador para manter a legibilidade. Resolvi estruturando em categorias claras.
- **Responsividade**: Garantir que o layout funcionasse em dispositivos móveis. Usei classes do Tailwind para flexbox e media queries.
- **Deploy no GitHub**: Inicialmente, tentei subir com o .gitignore, mas decidi removê-lo para incluir node_modules. Configurei o Git e fiz o push sem problemas após configurar o remote.
